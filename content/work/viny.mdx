## Problem

Cloud notes trade privacy for features. Local notes look like 2009. Power users want both on disk.

## What I built

An Electron editor. Files on disk, semantic search, a plugin surface. Ancestor of the Readied idea.

## One hard decision

The file is the source of truth. Features that need a proprietary store do not ship.
