---
title: "Migrating Images to Cloudinary"
line: Repo size down 99.7%.
---

The git repo was 450MB. After moving images to Cloudinary it dropped to 1.2MB.

## The problem

Images in the repo look convenient. Then clone is slow, CI is slow, nothing is optimized, and binary diffs are noise.

## Why Cloudinary

Automatic format conversion (WebP, AVIF). On-the-fly resize. A CDN. A usable free tier. A clean Next.js path.

## The move

Bulk upload. Point `images.remotePatterns` at `res.cloudinary.com`. Wrap URLs in a helper. Search-and-replace. About an hour.

## Results

Repo 450MB → 1.2MB. Build 3min → 45sec. Page load 2.4s → 0.8s with automatic WebP. Worth the hour.
